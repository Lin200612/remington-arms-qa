# Homepage Checklist (English)

Target: https://remington-arms.com/

Mark each item: Pass / Fail / Blocked / Not Run. Add notes and evidence for any Fail.

## Page load and layout
- [ ] Homepage opens over HTTPS.
- [ ] Page title is present and relevant.
- [ ] Main heading is visible.
- [ ] Main content is not obscured by overlapping elements.
- [ ] Images that are part of the page load or show an understandable fallback.
- [ ] No obvious horizontal overflow at desktop width.

## Header and navigation
- [ ] Header is visible.
- [ ] 700 Series link is visible and opens the intended public page.
- [ ] 870 Series link is visible and opens the intended public page.
- [ ] Owner's Manuals link is visible and opens the intended public page.
- [ ] Contact link is visible and opens the intended public page.
- [ ] Navigation can be used with keyboard focus.

## Main content
- [ ] Main informational sections are readable.
- [ ] Calls to action have meaningful labels.
- [ ] Links do not unexpectedly lead to unrelated domains.
- [ ] External links are distinguishable where practical.

## Footer

- [ ] Footer navigation links work.

## Responsive checks
- [ ] Layout is usable at  desktop viewport.

- [ ] Layout is usable at mobile viewport.
- [ ] Text and controls do not overlap.
- [ ] Navigation remains usable on a narrow screen.
