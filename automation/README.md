# UI Automation

Automation will be added after manual checks identify stable, public, read-only scenarios.

Planned stack:
- Python
- Playwright
- Pytest

Initial automation scope:
- Homepage responds and renders a recognizable page heading.
- Public navigation links are present.
- Selected public informational pages can be opened.

Do not automate form submission, purchases, account creation, restricted areas, or any weapon-related operational workflow. Keep execution low-volume and respectful of the website.
